# 01 · Las 3 campañas: laboratorio, remarketing y escala

Una sola cuenta con tres campañas fijas. No se crean campañas nuevas por cada idea: las
ideas entran como **anuncios** al laboratorio, y solo las que el juez aprueba suben a escala.

```
             ┌──────────────────────┐
 ideas  ───► │ 1 · LABORATORIO      │  muchos anuncios, poco presupuesto cada uno
             │ prueba y descarta     │
             └──────────┬───────────┘
                        │ ganador (juez)
                        ▼
             ┌──────────────────────┐
             │ 3 · ESCALA           │  pocos anuncios probados, la mayor parte del presupuesto
             └──────────────────────┘
             ┌──────────────────────┐
 gente que   │ 2 · REMARKETING      │  a quien ya nos vio o nos escribió y no cerró
 ya nos vio► │ prueba social, casos │
             └──────────────────────┘
```

## Reglas comunes

- **Objetivo:** Clientes potenciales (`OUTCOME_LEADS`) con optimización **Conversaciones** y
  destino **WhatsApp**. El resultado que mide el juez es *conversaciones iniciadas*.
- **Página:** Influence Chile SPA (`944811115371168`).
- **Público:** Chile, abierto, con Advantage+ Audience. El creativo es el que segmenta (si el
  anuncio habla a dueños de restaurantes, Meta encuentra dueños de restaurantes).
- **Ubicaciones:** Advantage+ (automáticas).
- **Nombres:** `MM · <n> <campaña> · ...` para que el juez las encuentre.
- **Todo se crea en pausa / borrador.** Nada sale al aire sin que un humano lo publique.

## 1 · Laboratorio

| | |
|---|---|
| Estructura | Presupuesto por conjunto (ABO). **Un conjunto por tanda semanal** (`Tanda 2026-S43`) con 4-6 anuncios nuevos |
| Presupuesto | ~50% del total (85% al principio, mientras no hay ganadores) |
| Qué entra | Cada semana: cortes del Lego System, imágenes de Higgsfield y posts orgánicos que funcionaron (`02`, `03`, `04`) |
| Quién decide | El juez, cada mañana: apaga los malos y marca los ganadores |

Por qué un conjunto por tanda: si todos los anuncios compiten en el mismo conjunto, Meta le da
todo el presupuesto al primero que despega y los demás nunca se prueban.

## 2 · Remarketing

| | |
|---|---|
| Estructura | Presupuesto de campaña (CBO), 1 conjunto |
| Público | Interactuaron con la página de Facebook en 365 días + le escribieron a la página. Cuando se conecte Instagram a la cuenta publicitaria, sumar interacciones de IG |
| Presupuesto | ~15% del total |
| Qué entra | Casos de clientes (antes/después), testimonios, la oferta concreta ("Plan Crecimiento $450.000"), objeciones respondidas |
| Regla | Frecuencia 7 días sobre 3 → rotar creativos |

## 3 · Escala

| | |
|---|---|
| Estructura | Presupuesto de campaña (CBO), 1 conjunto abierto |
| Qué entra | **Solo ganadores del laboratorio**, duplicados con el mismo ID de publicación para no perder comentarios y reacciones |
| Presupuesto | ~35% del total. Arranca en 0 hasta el primer ganador |
| Regla | Subir máximo **20% por día**. Si el costo 7 días sube 50% sobre el histórico del anuncio → fatiga, reemplazar por el siguiente ganador |

## Lo que ya sabemos de la cuenta

Del reporte inicial (`reportes/`, local):

- El ángulo **"¿Sientes que tus redes sociales podrían dar mucho más?"** es el mejor de la
  historia de la cuenta, con diferencia. Es el primer anuncio que entra a escala.
- Los anuncios con precio en el texto ("Planes desde $290.000", "PLAN CRECIMIENTO $450.000")
  traen conversaciones bastante más caras, pero probablemente más calificadas. Van a
  **remarketing**, no a público frío.
- Los formularios instantáneos costaron más por lead que una conversación de WhatsApp.
  WhatsApp se queda como destino principal.
